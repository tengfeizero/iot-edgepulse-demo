# 附录 A：生产 checklist（交付前逐项打勾）

> [← 返回教程目录](../README.md#教程目录生产级-iot-开发教程)

- [ ] 数据端到端不丢（4 层兜底全在）
- [ ] 重复数据业务无害（唯一键去重）
- [ ] 断网 24h + 断电恢复，数据 100% 可补
- [ ] 平台重启无数据丢失
- [ ] 所有链路 TLS 加密，无明文口令
- [ ] 设备权限最小化（只能碰自己的主题）
- [ ] 每层有心跳/指标，断链 5 分钟内可定位
- [ ] 存储有保留策略 + 备份 + 恢复演练
- [ ] 网关有看门狗 + 进程守护 + OTA 回滚
- [ ] 压力测试：设计 10 倍峰值流量验证不崩
