# 第 4 章 从本仓库到生产：改造路线图

> [← 返回教程目录](../README.md#教程目录生产级-iot-开发教程)

## 阶段 1：网关加固（1-2 周）

- [ ] 重连退避（指数退避 + 抖动），避免重连风暴
- [ ] 缓存容量上限 + 补报限速
- [ ] 配置从文件改为"云端下发 + 本地缓存"
- [ ] 进程守护（systemd 单元） + 看门狗
- [ ] 结构化日志 + 本地上报状态心跳

## 阶段 2：接入层高可用（1-2 周）

- [ ] Mosquitto → EMQX（单机起步，集群预留）
- [ ] TLS 开启 + 设备证书
- [ ] ACL 主题权限
- [ ] 订阅 LWT 遗嘱，平台感知设备离线

## 阶段 3：平台与存储加固（1-2 周）

- [ ] sink 改批量写入（攒批 5s/1000 条）
- [ ] 消费组多实例（同主题多消费者分摊）
- [ ] TDengine 副本 + 保留策略 + 降采样表
- [ ] 对账任务（设备计数 vs 平台计数）

## 阶段 4：可观测 + 运维（1-2 周）

- [ ] Prometheus 指标（上报率/积压/延迟）
- [ ] Grafana 看板 + 告警规则
- [ ] Docker Compose 一键部署
- [ ] 备份与恢复演练
