# 第 0 章 定位：本仓库代码是什么级别，生产还差什么

> [← 返回教程目录](../README.md#教程目录生产级-iot-开发教程)

先诚实定位：**本仓库是"教学演示级"，但它已经体现了 4 个生产级核心设计**：

| 已有能力 | 对应代码 | 生产级原则 |
|---|---|---|
| QoS 1 保证送达 | `publisher.js` / `subscriber.js` | 消息不丢 |
| 业务幂等去重 | `subscriber.js`（`deviceId + ts` 窗口去重） | 重复无害 |
| 断线缓存补报 | `gateway.js`（SQLite 缓存 + 重连补报） | 本地兜底 |
| 入库失败暂存重试 | `tsdb-sink.js`（pending 表 + 5 秒重试） | 存储兜底 |

**还缺的（生产差距）**：高可用、安全、可观测、性能调优、运维体系、配置管理、OTA——后续章节逐条讲。

> 一句话原则贯穿全文：**生产级 IoT 的本质 = 假设一切都会坏（网络断、机器挂、消息丢、数据乱），然后让系统在坏的情况下仍然不丢数据、不产生错误业务结论。**
