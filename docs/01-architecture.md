> [← 返回教程目录](../README.md#教程目录生产级-iot-开发教程)

## 1.1 分层架构（生产标准形态）

```
┌─────────────────────────────────────────────────────────┐
│  应用层：监控大屏、报表、MES/ERP 对接、告警、AI 分析        │
├─────────────────────────────────────────────────────────┤
│  平台层：规则引擎 · 数据服务 · 设备管理 · 用户权限          │
├─────────────────────────────────────────────────────────┤
│  接入层：MQTT Broker（EMQX 集群）· REST API 网关          │
├─────────────────────────────────────────────────────────┤
│  边缘层：协议网关（采集/缓存/边缘计算）                    │
├─────────────────────────────────────────────────────────┤
│  设备层：PLC / 仪表 / 传感器 / 控制器（RS485、以太网等）    │
└─────────────────────────────────────────────────────────┘
数据横向流：设备 → 边缘 → 接入 → 平台 → 存储(时序库) → 应用
指令纵向流：平台 → 接入 → 边缘 → 设备（ack 回执）
```

## 1.2 本仓库代码在架构中的位置

| 架构层 | 本仓库代码 | 生产替代/补充 |
|---|---|---|
| 设备层 | `modbus-sim.js`（模拟设备） | 真实设备 + 协议栈 |
| 边缘层 | `gateway.js` | 工业网关（ARM + Linux），加看门狗、配置管理 |
| 接入层 | Mosquitto | EMQX 集群（百万连接、规则引擎、数据集成） |
| 平台层 | `subscriber.js` / `control.js` | 正式平台服务（设备管理、鉴权、规则） |
| 存储层 | `tsdb-sink.js` + TDengine | 时序库集群（副本、保留策略、降采样） |
